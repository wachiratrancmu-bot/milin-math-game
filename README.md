# ⭐ ผจญภัยดาวคณิตของมิลิน

สร้างด้วย **React + Vite + TypeScript** ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ ไม่ต้องเข้าสู่ระบบ

## ✨ ความสามารถหลัก

- **แผนเตรียมสอบวันนี้ 4 ขั้น**: เรียนบทเรียนสั้น → ฝึกทักษะที่ควรฝึก → ทบทวนข้อที่เคยผิด → ทำข้อสอบจำลอง พร้อมนับถอยหลังถึงวันสอบ
- **บทเรียนสั้น 11 บท** สอนทีละขั้นพร้อมตัวอย่าง กรอบสิบช่อง และเส้นจำนวน แล้วให้ลองทำ 5 ข้อ
- **ฝึกตามบท ตามทักษะ หรือแบบรวม** บอกผลทันที ตอบผิดลองใหม่ได้ ผิดครบ 2 ครั้งจึงเฉลยพร้อมวิธีคิดทีละขั้น ตอบถูกไปข้อถัดไปเองใน 10 วินาที
- **ข้อสอบจำลอง 2 แบบ**: ปรนัย 20 ข้อ (ตามแนวข้อสอบ) หรือปรนัย 15 ข้อ + เติมคำตอบ 5 ข้อ (เหมือนแบบทดสอบย่อย) มีแถบข้อ ปักธงไว้กลับมาดู สรุปผลตามตัวชี้วัด และเฉลยทุกข้อ
- **รูปแบบข้อตรงกับข้อสอบของโรงเรียน**: ตัวเลือก ก ข ค · □ และ Δ · เส้นจำนวน · เขียนประโยคสัญลักษณ์ด้วยแป้นตัวเลข (+ − =)
- **คลังข้อสอบ 237 ข้อ** ทุกจำนวนไม่เกิน 20 ทุกข้อมีวิธีคิดทีละขั้น
- **แผนที่ทักษะ** แสดงระดับความชำนาญรายทักษะ และ **ทบทวนข้อที่เคยผิดแบบเว้นระยะ**
- **ระบบรางวัล**: สะสมดาวครบ 30 ดวงแลกรางวัล 1 ชิ้น และโบนัสเมื่อทำคะแนนเต็ม
- **ส่วนผู้ปกครอง (ล็อกด้วย PIN)**: ภาพรวมการเรียน · รางวัล · การตั้งค่า · เพิ่มข้อสอบเอง · หลักการออกแบบและเอกสารอ้างอิง
- ปุ่มฟังโจทย์ภาษาไทย · ปุ่มใหญ่สำหรับนิ้วเด็ก · ใช้แป้นพิมพ์ได้ · สีผ่านเกณฑ์คอนทราสต์ WCAG 2.2 ระดับ AA
- บันทึกความคืบหน้าในเครื่อง (localStorage) ไม่ส่งข้อมูลออกนอกเครื่อง

> **PIN เริ่มต้นคือ `1234`** (เปลี่ยนได้ในหน้าการตั้งค่าของผู้ปกครอง)

## 🚀 วิธีรันบนเครื่อง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install      # ติดตั้งครั้งแรกครั้งเดียว
npm run dev      # เปิดที่ http://localhost:5173
```

สร้างไฟล์สำหรับใช้งานจริง:

```bash
npm run build    # ได้ผลลัพธ์ในโฟลเดอร์ dist/
npm run preview  # ลองเปิดไฟล์ที่ build แล้ว
```

ตรวจคุณภาพโค้ด (CI รันให้อัตโนมัติก่อน deploy ทุกครั้ง):

```bash
npm run lint     # ตรวจด้วย ESLint
npm run test     # รันเทสต์ (Vitest) รวมการตรวจความถูกต้องของข้อสอบทุกข้อ
npm run format   # จัดรูปแบบโค้ดด้วย Prettier
```

## 🌐 การเผยแพร่บน GitHub Pages

ทุกครั้งที่ push ขึ้น branch `main` เวิร์กโฟลว์ `.github/workflows/deploy.yml` จะรัน lint → test → build
แล้วนำโฟลเดอร์ `dist/` ขึ้น branch `gh-pages` (ตั้งค่า **Settings → Pages → Source** เป็น branch `gh-pages`)

> โปรเจกต์ตั้ง `base: './'` และใช้ hash routing จึงใช้ได้ทั้ง GitHub Pages และโฮสต์อื่น ปุ่มย้อนกลับของเบราว์เซอร์ใช้งานได้

```

    curriculum.ts          ตัวชี้วัด ทักษะ บท และน้ำหนักข้อสอบจำลอง

  lib/

    learning.ts            ความชำนาญ การทบทวนแบบเว้นระยะ และการให้คะแนนข้อสอบ

    useHashRoute.ts        การเปลี่ยนหน้าด้วย hash
  state/                   การตั้งค่าและความคืบหน้า (React Context)
  components/
    Home.tsx               หน้าแรก แผนเตรียมสอบ แผนที่ทักษะ
    Lessons.tsx            บทเรียนสั้น
    PracticeSession.tsx    แบบฝึกและสรุปผล
    QuestionView.tsx       แสดงโจทย์ ตรวจคำตอบ และวิธีคิด
    ExamSession.tsx        ข้อสอบจำลอง
    Keypad.tsx             แป้นตัวเลขสำหรับข้อเติมคำตอบ
    NumberLine.tsx         เส้นจำนวน
    ModelView.tsx          กรอบสิบช่อง
    ParentArea.tsx         ส่วนผู้ปกครอง
docs/DESIGN.md             เอกสารการออกแบบและเอกสารอ้างอิง
```

## ➕ เพิ่มข้อสอบ

วิธีง่ายที่สุด: **ส่วนผู้ปกครอง → เพิ่มข้อสอบ** กรอกในหน้าเว็บได้เลย (เก็บในเครื่อง)

ถ้าต้องการเพิ่มถาวรในโค้ด ให้เพิ่มใน [`src/data/questions.ts`](src/data/questions.ts) โดยใช้ฟังก์ชันสร้างข้อที่มีอยู่
แล้วรัน `npm run test` เพื่อตรวจความถูกต้องอัตโนมัติ
